# Sin Star I

This SMILE 2.0 game is an initial scene-navigation shell.

## Controls

- Title screen: Up/Down or W/S selects an item; Enter or Space opens it.
- Placeholder scenes: Escape returns to the title screen.

The supplied title music plays only while the title screen is active. Opening any placeholder scene stops it, and returning with Escape restarts it.

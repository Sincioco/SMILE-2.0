# Renderer3D Soft Particles

This focused M7E-A test proves the shared native/Web soft-depth contract. It renders opaque geometry before a scene-depth snapshot, then draws one translucent particle with explicit intersection softness.

The automated project validates requested and effective modes, target dimensions and memory, pass counters, per-material policy, graceful disable, and cleanup. The visual lab added by the advanced-fire milestone provides the on/off comparisons used for mobile evidence.

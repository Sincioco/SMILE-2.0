# Phase4VisualSlice

The Phase 4 cross-backend proof uses original deterministic procedural assets generated by `scripts\generate-phase4-assets.ps1`.

It renders a 2304x1296 illustrated background into a 960x540 logical window, a transparent 2048x1024 two-state character sheet, and a transparent 1920x1080 foreground. It demonstrates full-image and explicit source/destination drawing, smooth scaling, alpha, opacity, anchors, horizontal flip, painter order, nested clipping, measured/dynamic text, and an intentionally small nearest-neighbor proof.

The same program also loads the character sheet twice to exercise shared cache ownership, persists an exact eight-byte block, overlaps two original WAV effects on explicit channels, and plays separate looping background music. State changes and four-frame animation are driven by `Timer()` milliseconds in ordinary SMILE records and arrays.

Open `Phase4VisualSlice.slnx` in Visual Studio 2026 Enterprise. Build either **Windows 64-bit .exe** or **Web**; set `GraphicsBackend` in the project to `DirectX` or `GDI` for an explicit backend check.

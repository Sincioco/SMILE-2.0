# Phase5UIStateTests

This Console project deliberately has no `Game Window`. It proves that a project can reference all of Smile.UI 2.0 and use pure `Menu` Class state members without graphics diagnostics. The package variant proves identical public capability metadata, constructor behavior, stale-facade safety, capacity handling, and idempotent destruction.

The separate invalid fixture calls `CurrentMenu.Draw()` and must receive exactly one `SML3704` at its call site.

# Phase5SubmenuViewport

Focused DirectX/GDI/Web visual fixture for Phase 5.2.1. It demonstrates a fixed left cursor gutter, exact ` >` indicator modes, cursors on all visible levels, system/bitmap ellipsis, bounded two-line wrapping, viewport placement, and compact proportional-scrollbar proofs for 4-of-5, 4-of-20, 4-of-64, all-visible, hidden, and tiny-track cases.

Controls:

```text
Up/Down       move
Right/Enter   open submenu
Left/Escape   close one level
1             system text
2             bitmap text
```

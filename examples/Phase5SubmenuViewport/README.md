# Phase5SubmenuViewport

Focused DirectX/GDI/Web visual fixture for Phase 5.2. It demonstrates a fixed left cursor gutter, automatic ` >` markers, inactive ancestor focus, system/bitmap ellipsis, bounded two-line wrapping, right/left placement, bottom-edge upward adjustment, narrow overlap with painter-order safety, and three active submenu levels.

Controls:

```text
Up/Down       move
Right/Enter   open submenu
Left/Escape   close one level
1             system text
2             bitmap text
```

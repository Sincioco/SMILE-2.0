# Phase3BRecords

This sample consumes `Smile.Data.Models` through both a project reference and a built package reference. It proves nested records, record copying, record arrays, ByVal, ByRef, scalar field ByRef, record returns, native/Web parity, and Text ownership.

Its `With...End With` coverage proves nested leading-dot field access, exact-once evaluation of an indexed record target, a leading-dot field passed `ByRef`, and visibility after the same record root is replaced through `ByRef`.

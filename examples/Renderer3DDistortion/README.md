# Renderer3D M7E-B Distortion Lab

This deterministic native/Web parity lab covers the opt-in heat-distortion vector and composite pass.

It validates half- and quarter-resolution quality modes, HDR and direct-LDR scene paths, material diagnostics, zero-emitter behavior, low-quality disablement, and forced allocation fallback.

Run `scripts\test-renderer3d-distortion.ps1` from the repository root.

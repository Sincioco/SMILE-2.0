Turn Game Data Into Pictures

Drawing does not change the rules. It shows the player what the current variables mean.

Paste the DrawBoard routine

This is the complete gameplay renderer.

Checkpoint 7 — exact official code
SUB DrawBoard()
    CLEAR RGB(10, 18, 35)
    FILL RECTANGLE FieldX, FieldY, FieldWidth, FieldHeight, BLACK
    DRAW RECTANGLE FieldX, FieldY, FieldWidth, FieldHeight, RGB(40, 70, 95)

    FOR I = 0 TO Length - 1
        IF SnakeX[I] >= 0 AND SnakeX[I] < GridWidth AND SnakeY[I] >= 0 AND SnakeY[I] < GridHeight THEN
            FILL RECTANGLE FieldX + SnakeX[I] * CellSize + 2, FieldY + SnakeY[I] * CellSize + 2, 16, 16, RGB(60, 230, 75)
            DRAW RECTANGLE FieldX + SnakeX[I] * CellSize + 2, FieldY + SnakeY[I] * CellSize + 2, 16, 16, RGB(20, 105, 35)
        END IF
    END FOR

    FILL RECTANGLE FieldX + FoodX * CellSize + 3, FieldY + FoodY * CellSize + 3, 14, 14, RGB(245, 45, 55)
    DRAW RECTANGLE FieldX + FoodX * CellSize + 3, FieldY + FoodY * CellSize + 3, 14, 14, RGB(120, 15, 25)

    DRAW TEXT "SMILE SNAKE" AT 835, 55 SIZE 27 COLOR LIGHT_GREEN CENTERED
    DRAW TEXT "SCORE" AT 755, 115 SIZE 20 COLOR LIGHT_GRAY
    DRAW NUMBER Score AT 755, 142 SIZE 34 COLOR YELLOW
    DRAW TEXT "HIGH SCORE" AT 755, 205 SIZE 20 COLOR LIGHT_GRAY
    DRAW NUMBER HighScore AT 755, 232 SIZE 34 COLOR CYAN
    DRAW TEXT "WASD / ARROWS" AT 835, 330 SIZE 16 COLOR WHITE CENTERED
    DRAW TEXT "MOVE THE SNAKE" AT 835, 355 SIZE 16 COLOR LIGHT_GRAY CENTERED
    DRAW TEXT "ALT+ENTER" AT 835, 415 SIZE 16 COLOR WHITE CENTERED
    DRAW TEXT "FULL SCREEN" AT 835, 440 SIZE 16 COLOR LIGHT_GRAY CENTERED
    DRAW TEXT "ESCAPE EXITS" AT 835, 490 SIZE 16 COLOR LIGHT_GRAY CENTERED
END SUB

Draw one segment from its grid coordinate

The segment position formula
            FILL RECTANGLE FieldX + SnakeX[I] * CellSize + 2, FieldY + SnakeY[I] * CellSize + 2, 16, 16, RGB(60, 230, 75)

Why 16 × 16?

Each cell is 20 × 20. A 16-pixel segment with a 2-pixel margin on every side creates visible gaps.

Why food is 14 × 14

A 3-pixel margin makes the red food slightly smaller than a snake segment.

Does DrawBoard change the score or snake position?

No. It reads the current data and turns it into a picture. The rules live in update routines such as MoveSnake.

Drawing reads game data; it does not change movement, score, or collision rules.

Which formula turns a segment’s grid X into its drawing X?

Check your answer

FieldX + SnakeX[I] × CellSize + 2. You first met the same math in Grid & Coordinates.

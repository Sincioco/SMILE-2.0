Objects, Arrays & Game Memory

Pictures are only the display. The real game is information—and closely related information is easier to understand when one focused object protects it.

Private arraysClass identityGame-level stateHighScore

The Snake Class stores matching coordinate lists

SegmentXs[0] and SegmentYs[0] describe the head. Index 1 is the next segment, index 2 is the next, and so on. These arrays are Private, so game code asks the object through HeadX, HeadY, Length, SegmentX(), and SegmentY().

SnakeModel.smile — private intrinsic state
    Private SegmentXs[840] As Number
    Private SegmentYs[840] As Number
    Private CurrentLength As Number
    Private CurrentDirection As MoveDirection
    Private RequestedDirection As MoveDirection
    Private TailX As Number
    Private TailY As Number

Array

A numbered collection of storage slots. SegmentXs[840] reserves slots numbered 0 through 839.

Encapsulation

The Class can maintain its own rules because other code cannot change its private slots directly.

Put each fact at the right level

OwnerFactsWhy
Snake ClassSegments, length, current/requested direction, saved tailThey describe one snake and must stay consistent together.
GridPoint TypeFood.X, Food.YA coordinate is a small copyable value.
Startup programScore, high score, timing, food policy, audio, drawing, GameStateThey describe the whole round or application—not the snake itself.

Assignment versus comparison

On a normal line, Score = 0 means “store zero in Score.” Inside an If condition, Score = HighScore asks whether the values are equal. Context tells the equals sign which job it has.

Arrays & Game Memory

Pictures are only the display. The real game is the information stored in variables and array slots.

SnakeX[]SnakeY[]BooleansHighScore

Store the body as matching coordinate lists

SnakeX[0] and SnakeY[0] describe the head. Index 1 is the next segment, index 2 is the next, and so on. The variable Length tells the program how many slots are active.

Array

A numbered collection of storage slots. SnakeX[840] reserves slots numbered 0 through 839.

Index

The number inside brackets. It selects one slot, such as SnakeY[4].

Variables remember changing facts

VariableQuestion it answers
LengthHow many snake segments are active?
DirectionWhich direction is being used for the current move?
NextDirectionWhich safe direction did the player request next?
FoodX, FoodYWhich grid square contains food?
ScoreHow many points has the player earned?
FoodValid, CollisionAre these yes/no facts True or False?
StateAre we on the title, playing, or game-over screen?

Assignment versus comparison

On a normal line, Score = 0 means “store zero in Score.” Inside an If condition, Score = HighScore asks whether the values are equal. Context tells the equals sign which job it has.

Repetition builds memory

SnakeX[I] and SnakeY[I] are a matching pair: together they locate segment I.

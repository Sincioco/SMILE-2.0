Move, Collide, Grow, and Speed Up

The Snake class owns body movement and collision questions. The startup routine coordinates score, sound, and timing.

Model behaviorPrivate stateProgram orchestration

Two files, one rule flow

Paste the object behavior into SnakeModel.smile. Paste the orchestration routine into Program-NoDemo.smile. The project compiles them together.

6A

Accept a safe direction request

The object rejects a reverse turn before remembering the request.

Checkpoint 6A — Snake.TryTurn
    Public Sub TryTurn(Direction As MoveDirection)

        If Not Me.IsReverse(Direction) Then
            Me.RequestedDirection = Direction
        End If

    End Sub

The keyboard layer translates W, A, S, D, and arrow keys into MoveDirection values. The model never depends on keyboard constants.

6B

Shift the body and move the head

Move saves the old tail, copies body coordinates backward, then changes one head coordinate.

Checkpoint 6B — Snake.Move
    Public Sub Move()

        Dim I As Number

        Me.CurrentDirection = Me.RequestedDirection
        Me.TailX = Me.SegmentXs[Me.CurrentLength - 1]
        Me.TailY = Me.SegmentYs[Me.CurrentLength - 1]

        For I = Me.CurrentLength - 1 Down To 1
            Me.SegmentXs[I] = Me.SegmentXs[I - 1]
            Me.SegmentYs[I] = Me.SegmentYs[I - 1]
        End For

        Select Case Me.CurrentDirection
            Case MoveDirection.Up
                Me.SegmentYs[0] = Me.SegmentYs[0] - 1

            Case MoveDirection.Down
                Me.SegmentYs[0] = Me.SegmentYs[0] + 1

            Case MoveDirection.Left
                Me.SegmentXs[0] = Me.SegmentXs[0] - 1

            Case MoveDirection.Right
                Me.SegmentXs[0] = Me.SegmentXs[0] + 1
        End Select

    End Sub
6C

Grow from the saved tail

Grow returns a Boolean so the program knows whether capacity was available.

Checkpoint 6C — Snake.Grow
    Public Function Grow() As Boolean

        If Me.CurrentLength >= 840 Then
            Return False
        End If

        Me.SegmentXs[Me.CurrentLength] = Me.TailX
        Me.SegmentYs[Me.CurrentLength] = Me.TailY
        Me.CurrentLength = Me.CurrentLength + 1

        Return True

    End Function
6D

Coordinate model and presentation

The program asks the model to move and answer rule questions, then handles sound, score, food, and timing.

Checkpoint 6D — Program MoveSnake
Sub MoveSnake()

    Dim Collision As Boolean
    Dim Grew As Boolean

    Call Player.Move()

    Collision = Player.HitWall(GridWidth, GridHeight)
    Collision = Collision Or Player.HitSelf()

    If Collision Then

        Call EndRound()

    Else If Player.HeadX = Food.X And Player.HeadY = Food.Y Then

        Grew = Player.Grow()

        If Grew Then
            Score = Score + 10
            MoveDelay = Max(MinimumDelay, StartDelay - (Score / 50) * 4)
        End If

        Play Sound "Assets\Eat.wav"
        Call SpawnFood()

    End If

    NextMoveTime = Timer() + MoveDelay

End Sub

The eating sequence

  1. Ask Player.Grow() to restore the saved tail.
  2. If growth succeeded, add 10 points.
  3. Recalculate movement delay.
  4. Play Eat.wav.
  5. Spawn new food.

Read the speed formula

Max(MinimumDelay, StartDelay - (Score / 50) * 4) means: every 50 points, subtract 4 milliseconds, but never become faster than the 45-millisecond minimum.

At score 250, what is MoveDelay?

250 / 50 = 5. Then 100 − (5 × 4) = 80 milliseconds.

What you need

Software and files

  • The SMILE 2.0 source repository
  • Visual Studio 2026 with the SMILE 2.0 extension
  • The folder games\Snake
  • Curiosity, patience, and permission to make mistakes

Your learning sources

The repository has two startup programs. Program.smile includes arcade attract/demo behavior. Program-NoDemo.smile removes that demo logic. Both use SnakeModel.smile, which owns the focused object model.

The Snake project tree

This is a file tree. Each line is one file or folder, and the branch characters show what belongs inside the folder.

games\Snake
├── Snake.slnx
├── Snake.smileproj
├── Program.smile                 (includes demo mode)
├── Program-NoDemo.smile          (our teaching source)
├── SnakeModel.smile              (shared object model)
└── Assets
    ├── Start.wav
    ├── Eat.wav
    └── GameOver.wav

Use the existing assets

You do not need to create new sound files. The game already contains Assets\Start.wav, Assets\Eat.wav, and Assets\GameOver.wav.

How this tutorial finds the game

The website is designed to live beside the rest of the SMILE 2.0 project, not inside the game folder.

From a tutorial page, the relative path ../../games/Snake goes up two folders and then enters the official Snake game folder.

Make a safe practice copy

  1. Use the link above or open <SMILE-2.0-root>\games\Snake\Snake.slnx in Visual Studio.
  2. Make backup copies of Program-NoDemo.smile and SnakeModel.smile.
  3. Open Snake.smileproj as text.
  4. Confirm it includes SnakeModel.smile, then change its startup file from Program.smile to Program-NoDemo.smile.
Snake.smileproj — the line to use
<StartupFile>Program-NoDemo.smile</StartupFile>

First discovery mission

Before clearing your practice copy, run the finished no-demo game once. Watch the title screen, move the snake, eat one food, hit a wall, and retry.

What three screens did you see?

Title, Playing, and Game Over. Later we will name them with a GameState Enum.

The partial program will not run yet

The checkpoints introduce two cooperating files by concept. Your tutorial copy becomes complete after Checkpoint 9. Until then, use the untouched original when you want to see the destination.

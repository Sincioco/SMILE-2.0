Place Food Safely

A random square is not automatically a good square. The program must prove that food does not overlap the snake.

Paste the SpawnFood routine

Paste directly below the high-score Load.

Checkpoint 3 — exact official code
Sub SpawnFood()

    FoodValid = False

    Do
        Random FoodX From 0 To GridWidth - 1
        Random FoodY From 0 To GridHeight - 1
        FoodValid = True

        For I = 0 To Length - 1

            If FoodX = SnakeX[I] And FoodY = SnakeY[I] Then
                FoodValid = False
            End If

        End For

    Loop Until FoodValid = True

End Sub

The algorithm in plain language

  1. Assume the position is not valid.
  2. Pick random X and Y values inside the board.
  3. Temporarily mark the square valid.
  4. Look at every active snake segment.
  5. If both X and Y match a segment, mark it invalid.
  6. Repeat until a valid square is found.

Why does random X stop at GridWidth − 1?

A 35-column board is numbered 0 through 34. Column 35 would be outside the board.

Repetition builds memory

Reinforce what you learned

Say it again

Food placement repeats: choose a square, assume it is valid, scan every segment, and retry when occupied.

Recall it

Why does the loop stop only when FoodValid = True?

Check your answer

Because True means no snake segment occupies the chosen square. The same array scan idea returns during self-collision.

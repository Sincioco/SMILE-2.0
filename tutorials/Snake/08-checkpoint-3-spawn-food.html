Place Food Safely

A random square is not automatically a good square. The program must prove that food does not overlap the snake.

Sub routineRandom numbersLoop until valid
3

Paste the SpawnFood routine

The startup program chooses a candidate square; the Snake object decides whether that square is occupied.

Checkpoint 3 — exact official code
Sub SpawnFood()

    Dim FoodValid As Boolean
    Dim NewX As Number
    Dim NewY As Number

    FoodValid = False

    Do
        Random NewX From 0 To GridWidth - 1
        Random NewY From 0 To GridHeight - 1

        Food.X = NewX
        Food.Y = NewY

        FoodValid = Not Player.Contains(Food.X, Food.Y)

    Loop Until FoodValid = True

End Sub

The algorithm in plain language

  1. Assume the position is not valid.
  2. Pick candidate X and Y values inside the board.
  3. Store them together in Food.
  4. Ask Player.Contains whether the snake occupies that square.
  5. Negate the answer: an unoccupied square is valid.
  6. Repeat until a valid square is found.

Why does random X stop at GridWidth − 1?

A 35-column board is numbered 0 through 34. Column 35 would be outside the board.

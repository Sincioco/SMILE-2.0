Multiline parenthesized expressions

A normal newline ends a SMILE expression. Parentheses explicitly allow a long expression or call argument list to continue on following lines. Keep a complete If ... Then line on one line when it is at most 100 characters and has no more than two top-level Boolean clauses. Otherwise use one clause per line and the preferred trailing-operator style.

If (SnakeX[0] < 0 Or
    SnakeX[0] >= GridWidth Or
    SnakeY[0] < 0 Or
    SnakeY[0] >= GridHeight) Then
    Collision = True
End If

Leading operators are also legal. Keep Then on the same physical line as the closing parenthesis. Without the opening parenthesis, a newline still ends the expression.

Why the syntax is blue

The tutorial uses blue for SMILE language syntax because that is how the student sees keywords in Visual Studio. Decorative purple may appear elsewhere, but it does not identify language syntax.

Case-insensitive language

SMILE accepts any keyword capitalization. Official SMILE 2.0 source uses Visual Basic-style initial capitalization for keywords and ordinary identifiers. Do not write keywords or ordinary variables in all caps; established constants may remain uppercase.

Official SMILE 2.0 formatting

  • Place the game window and main loop near the top so the program’s main flow appears before supporting procedures.
  • Use one blank line to separate logical groups and important SMILE statements. Never use double or triple blank lines.
  • Keep a short If ... End If branch compact when it contains only one statement. Add interior space when a branch contains several steps.
  • Separate a standalone Call or Play Sound statement from surrounding assignment groups; keep consecutive statements of the same kind together.
  • Wrap a long If condition in parentheses and continue one Boolean clause per line, as shown above.
  • A function may return True, False, a constant, or a literal string directly. Assign a computed expression to a clearly named variable before returning it.

Where to learn the larger language

Snake uses only part of SMILE 2.0. The final Book 11 Language Visual Guide will also cover functions, Select Case, two-dimensional arrays, arcs, circles, lines, quadrilaterals, text-file loading, MP3 music, and the rest of the current language.

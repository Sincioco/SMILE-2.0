Our promise

No mystery code. Every SMILE statement, formula, game mechanic, and programming idea used by Snake is explained in plain language. Every code block has a Copy button.

Designed for the SMILE 2.0 repository

Install this website at <SMILE-2.0-root>\tutorials\Snake. Its live project and sound links then point to ../../games/Snake, which resolves to <SMILE-2.0-root>\games\Snake.

Here, <SMILE-2.0-root> means whichever folder contains the student’s SMILE 2.0 repository; no drive letter or fixed installation folder is assumed.

How to use the tutorial

1. Read the idea

Understand the small problem before touching the code.

2. Copy one piece

Use the Copy button and paste the exact official code below the previous checkpoint.

3. Predict and test

Say what you expect, run the game when the source is complete, and compare reality with your prediction.

How repetition helps you learn

Important ideas return several times. Each return adds a new piece instead of asking you to memorize everything at once.

Meet it

See the idea with a picture and plain-language explanation.

Use it again

Paste it into the game, then meet the same syntax in another job.

Recall it

Predict, explain, and answer a tiny question before revealing the answer.

Programmer thinking

A hard problem becomes easier when you split it into small questions. “How do I make Snake?” is huge. “Where is the head?” “Which direction is it moving?” and “Did it touch food?” are small questions.

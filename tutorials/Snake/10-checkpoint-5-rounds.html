Start and Finish a Round

Small routines let the main loop use clear verbs instead of repeating setup and cleanup details.

ResetPlayEndRoundSound and storage
5

Paste ResetPlay and EndRound

These two routines define the round lifecycle.

Checkpoint 5 — exact official code
Sub ResetPlay()

    Call Player.Reset()

    Score = 0
    MoveDelay = StartDelay

    Call SpawnFood()

    NextMoveTime = Timer() + StartDelay
    State = GameState.Playing

    Play Sound "Assets\Start.wav"

End Sub

Sub EndRound()

    Stop Music
    State = GameState.GameOver

    If Score > HighScore Then
        HighScore = Score
        Save HighScore To "HighScore"
    End If

    Play Sound "Assets\GameOver.wav"

End Sub

ResetPlay()

  1. Ask Player to reset itself.
  2. Reset score and delay.
  3. Spawn food.
  4. Schedule the first move.
  5. Choose GameState.Playing.
  6. Play Start.wav.

EndRound()

  1. Choose GameState.GameOver.
  2. Compare score and high score.
  3. Save a new high score.
  4. Play GameOver.wav.

Timing formula

NextMoveTime = Timer() + StartDelay schedules the first move instead of freezing the whole program.

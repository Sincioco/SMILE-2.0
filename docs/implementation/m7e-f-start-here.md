# Start here — native thermal fire checkpoint

This package records the native Fire Lab and shared arena/UI/backdrop milestone before Arin's flaming-sword integration. It is not a claim that free-roam Arin, full-blade attack trails or M7E-G endurance are complete.

Reading order:

1. `docs/implementation/native-thermal-turbulence-fire-m7e-f.md`: implementation, validation, limits and next stage.
2. `docs/implementation/screenshots/m7e-f-native-thermal-fire/10-iphone-contact-sheet.png`: quick visual overview.
3. The adjacent `screenshot-index.md` and `native-validation.txt`: capture provenance, exact hashes and measurements.
4. `examples/AdvancedFireVfxLab/README.md` and `tools/Character3DViewer/README.md`: current controls/build instructions.
5. `libraries/Smile.Simple3D/API.md` and `libraries/Smile.UI/API.md`: shared APIs.
6. `TechnicalAssets/Generation3/Fire/README.md`: deterministic source-asset provenance.

The ZIP keeps these documents and companion examples/configuration under `Repository-Files` with repository-relative paths. Run native programs from the repository builds, not from documentation ZIP contents. Fire Lab's persistent position/size uses its stable application ID. Arin's saved corrections remain in the canonical ArinV57 package, outside disposable build outputs.

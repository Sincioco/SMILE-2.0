# How to hand this revision to Codex

This package supersedes the earlier Phase 1B package.

1. Extract it somewhere accessible to Codex.
2. Give Codex `COPY-PASTE To CODEX.txt`.
3. Tell Codex the latest user observation is authoritative:
   - the file is created and opens;
   - it is included enough for Add Existing to detect it;
   - it is invisible in Solution Explorer even after restart.
4. Codex must read every numbered document and companion file before editing.

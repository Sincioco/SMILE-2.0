# SMILE 2.0 Arcade Expansion Codex Package

Start with:

```text
Codex-Instructions\00 - START HERE - SMILE 2.0 Arcade Expansion Mission.md
```

The individual instructions are intentionally separated so Codex can implement and commit one coherent milestone at a time.

Ready-to-copy Dungeon Star I educational files are under:

```text
Repository-Files\games\DungeonStarI\
```

The package includes:

- 12 Markdown instruction/specification files;
- a student-facing Dungeon Star I map-authoring guide;
- `default.map`;
- `sample-loops.map`;
- `sample-switchbacks.map`.

The map files were structurally validated when this ZIP was created for:

- three floors;
- 31-by-31 rows;
- legal symbols;
- closed borders;
- connectivity;
- door orientation;
- no 2-by-2 open areas;
- required starts/stairs.

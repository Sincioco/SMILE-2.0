# Smile.Game 2.0.0

Five ordinary SMILE modules provide typed cardinal movement, deterministic sprite animation, transactional SMILE-MAP 1 loading and visible tile rendering, clamped 2D cameras, and generic collision predicates. `CardinalMover` and `CameraState` are deep-copy value Types with instance methods; Animation and TileMap remain generation-safe handle Modules, and Collision2D remains stateless. The package owns no window, assets, UI, audio, scenes, RPG data, or application rules.

See [the public API](../../docs/libraries/smile-game-api.md), [map format](../../docs/formats/smile-map-format-1.md), and [Phase 7 architecture](../../docs/architecture/phase7-top-down-rpg-world.md).

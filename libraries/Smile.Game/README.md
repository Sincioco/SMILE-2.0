# Smile.Game 1.0.0

Five ordinary SMILE modules provide fixed-step cardinal movement, deterministic sprite animation, transactional SMILE-MAP 1 loading and visible tile rendering, clamped 2D cameras, and generic collision predicates. The package owns no window, assets, UI, audio, scenes, RPG data, or application rules.

See [the public API](../../docs/libraries/smile-game-api.md), [map format](../../docs/formats/smile-map-format-1.md), and [Phase 7 architecture](../../docs/architecture/phase7-top-down-rpg-world.md).

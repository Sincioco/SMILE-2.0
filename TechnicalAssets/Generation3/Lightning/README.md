# Generation 3 Lightning Assets

These neutral white source textures are generated locally by
`scripts\generate-lightning-vfx-assets.ps1`. They contain no third-party art.
Runtime color, intensity, HDR emission, width, branching, and motion come from
`Smile.Simple3D.LightningVfx3D`.

Run the generator with `-Check` to verify byte-for-byte reproducibility.

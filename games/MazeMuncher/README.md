# Maze Muncher

Maze Muncher is an original neon maze-chase arcade sample written entirely in SMILE 2.0. Eat every pellet, use power pellets to turn the tables on four geometric enemies, and escape through the horizontal wrap tunnel.

Two complete teaching sources are included:

- `Program.smile` is the startup version and includes the five-second attract demo, demo player AI, safety timer, cancellation, and direct return to the title when the demo ends.
- `Program-NoDemo.smile` contains the complete user-playable game with all demo-related code removed, making the core parser, movement, enemies, scoring, power mode, and rendering easier to study.

## Controls

- Arrow keys or W/A/S/D: buffer the next direction.
- Enter or Space: start or retry.
- Escape: return to the title during play; exit from the title.
- Alt+Enter: toggle borderless fullscreen through the shared runtime.

In `Program.smile`, five idle seconds starts an attract demo, any key cancels it, and completion returns directly to the title. To study or build the simpler version, change `<StartupFile>` in `MazeMuncher.smileproj` to `Program-NoDemo.smile`.

The playfield uses continuous two-tone blue wall contours on black, keeping the maze visually open while preserving the exact map and collision geometry.

`Maps\default.map` is parsed and validated by `Program.smile`. Missing or invalid map data falls back to a deterministic safe maze. The WAV effects are original deterministic tones generated by `scripts\generate-sounds.ps1`. `Assets\Background.mp3` loops only while a player or attract-demo character is actively alive and moving; it stops for the title, caught-player pause, level-clear pause, and terminal screen.

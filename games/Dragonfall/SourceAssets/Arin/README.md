## Prototype profile

- 6,631 vertices, 29,922 indices, and 9,974 triangles.
- 30 source mesh primitives deterministically coalesced into one compatible SM3D runtime part.
- One PBR material with embedded 1,024 x 1,024 base-color, normal, and metallic-roughness JPEG images externalized to PNG.
- 41 deformation bones, 73 nodes, and at most four joint influences per vertex.
- Source clips: `preset:biped:idle`, `preset:biped:walk`, and `preset:biped:run`.
- Descriptor-authored prototype events: left/right footsteps for Walk and Run.
- Descriptor-authored sockets: Root, Head, Chest, SwordBase, SwordTip, and ShieldCenter.

The prototype does not contain Dragonfall's complete production combat clip set or authored weapon/shield socket nodes. The Dragonfall adapter tries production clip names first and uses explicit prototype-only Idle/Run fallbacks for this asset.

## Reproduction

From the repository root:

```powershell
& .\scripts\prepare-dragonfall-arin-prototype.ps1
& .\scripts\prepare-dragonfall-arin-prototype.ps1 -Check
```

The first command updates the prepared and runtime outputs. `-Check` regenerates into `artifacts\temp`, compares hashes with the repository copies, and leaves tracked files untouched.

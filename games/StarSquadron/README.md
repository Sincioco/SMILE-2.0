# Star Squadron

Star Squadron is an original full-16:9 fixed-screen space shooter written entirely in SMILE 2.0. A 72-star multi-speed field spans the 960-by-540 canvas while a 40-enemy formation drifts, fires, dives through piecewise paths, and returns to formation. The player has three lives, three simultaneous shots, stage progression, escalating attacks, geometric explosions, score, and a persistent high score.

Two complete teaching sources are included:

- `Program.smile` includes the five-second attract demo and survival-first player AI. Any key cancels the demo; its 45-second limit or natural end returns directly to the title.
- `Program-NoDemo.smile` keeps the complete player game while removing demo AI, lifecycle, safety, timers, UI, automatic launch, and cancellation code.

To build the student edition in Visual Studio, change `<StartupFile>` in `StarSquadron.smileproj` to `Program-NoDemo.smile`.

## Controls

- A/D or Left/Right: move the ship.
- Space: fire.
- Enter or Space: start or retry.
- Escape: return to title during play; exit from the title.
- Alt+Enter: toggle borderless full screen through the shared runtime.

All player rules, enemy behavior, demo AI, collisions, fixed-point movement, stage logic, and rendering remain in `.smile`. The WAV effects are original deterministic tones generated by `scripts\generate-sounds.ps1`.

# Paddle Ball

`Program.smile` is the normal Paddle Ball game with its computer-versus-computer attract demo. `Program-NoDemo.smile` keeps one-player and local two-player modes, the one-player opponent, scoring, rally tracking, rendering, and sounds while removing demo paddle control and lifecycle code.

To study or build the simpler version in Visual Studio, change `<StartupFile>` in `PaddleBall.smileproj` to `Program-NoDemo.smile`.

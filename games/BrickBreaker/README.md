# Brick Breaker

`Program.smile` is the normal Brick Breaker game with its attract demo. `Program-NoDemo.smile` keeps player paddle control, ball and brick physics, lives, levels, scoring, high score, rendering, and sounds while removing demo prediction, recovery, stall breaking, and lifecycle code.

To study or build the simpler version in Visual Studio, change `<StartupFile>` in `BrickBreaker.smileproj` to `Program-NoDemo.smile`.

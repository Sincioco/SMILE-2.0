# Falling Blocks

`Program.smile` is the normal Falling Blocks game with its attract demo. `Program-NoDemo.smile` keeps manual movement, rotation, falling, hard drop, animated row clears, scoring, levels, high score, music, and sounds while removing demo planning and automatic play.

To study or build the simpler version in Visual Studio, change `<StartupFile>` in `FallingBlocks.smileproj` to `Program-NoDemo.smile`.
